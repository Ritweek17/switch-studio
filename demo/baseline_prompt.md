# One-shot baseline prompt

This is the plain prompt used for `demo/baseline.md`. It provides the saved
fixture snapshot directly and does not ask for citations or use the Switch
Studio fact/verifier pipeline.

> You are writing a short project update for a teammate. Read the repository
> snapshot below and summarize what changed in the `v0.1..HEAD` range in two or
> three sentences. Highlight the verifier work and whether the project is ready
> for a demo. Do not use a structured fact list or citation format.
>
> Snapshot: `schemas/examples/snapshot.json`
